# cdsap/homebrew-tap

Homebrew tap for cdsap CLIs:

- [Daemonitor](https://github.com/cdsap/daemonitor)
- [ProjectGenerator](https://github.com/cdsap/ProjectGenerator)

```bash
brew tap cdsap/tap
brew trust cdsap/tap   # required on Homebrew 7+
brew install daemonitor-cli
brew install project-generator
```
